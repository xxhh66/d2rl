| 算法             | 核心公式             | 与前者的关系  | 主要改进     |
| :--------------- | :------------------- | :------------ | :----------- |
| **MP**           | $P(s'\|s)$           | 最基础        | 马尔科夫性   |
| **MRP**          | $V=R+γPV$            | MP + 奖励     | 添加奖励信号 |
| **MDP**          | $V=max[R+γPV]$       | MRP + 动作    | 添加决策     |
| **策略迭代**     | 策略评估+提升        | MDP求解       | 交替进行     |
| **价值迭代**     | $V←max[R+γPV]$       | MDP求解       | 直接求最优   |
| **MC**           | $V←V+α[G-V]$         | 从经验学习    | 不需要模型   |
| **TD**           | $V←V+α[r+γV'-V]$     | MC改进        | 单步更新     |
| **Q-Learning**   | $Q←Q+α[r+γmaxQ'-Q]$  | TD改进        | Off-policy   |
| **SARSA**        | $Q←Q+α[r+γQ'-Q]$     | TD改进        | On-policy    |
| **REINFORCE**    | $θ←θ+α∇logπ·G$       | 策略梯度基础  | 直接优化策略 |
| **Actor-Critic** | $θ←θ+α∇logπ·δ$       | REINFORCE改进 | 降低方差     |
| **PPO**          | $L=min(rA,clip(r)A)$ | AC改进        | 稳定训练     |
