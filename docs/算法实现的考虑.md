﻿# MC → TD → Q-learning → SARSA → REINFORCE → Actor-Critic → PPO 代码实现考虑

## 1. 总体视角

这一组算法可以按两条主线理解：

第一条是价值函数路线：

$$
\text{MC}
\rightarrow
\text{TD}
\rightarrow
\text{SARSA / Q-learning}
\rightarrow
\text{DQN}
$$

第二条是策略梯度路线：

$$
\text{REINFORCE}
\rightarrow
\text{Actor-Critic}
\rightarrow
\text{PPO}
$$

代码实现时需要统一考虑：

1. 环境接口；
2. 状态表示；
3. 动作空间；
4. 奖励函数；
5. episode 终止条件；
6. 采样策略；
7. 学习目标；
8. 价值更新或策略更新；
9. 价值评估；
10. 日志、模型保存与测试评估。

## 2. 公共代码结构

无论实现哪种算法，建议把代码拆成以下模块：

```bash
project/
├── env_wrapper.py       # 环境封装
├── agent.py             # 算法主体
├── replay_buffer.py     # 经验回放，DQN/PPO 等用
├── model.py             # 神经网络模型
├── train.py             # 训练入口
├── evaluate.py          # 测试评估
├── config.py            # 超参数配置
└── utils.py             # 日志、随机种子、绘图等
```

训练循环通常可以抽象为：

```python
for episode in range(num_episodes):

    state = env.reset()

    while not done:

        action = agent.select_action(state)

        next_state, reward, terminated, truncated, info = env.step(action)

        agent.store_or_update(state, action, reward, next_state, done)

        agent.learn()

        state = next_state

    agent.end_episode_update()
```

需要特别注意：终止、截断

$$
done = terminated \lor truncated
$$

但是在 TD bootstrap 中，通常只有真实终止 `terminated=True` 才应阻断未来价值。

## 3. 环境与状态设计

### 3.1 状态 State

状态是算法输入：

$$
S_t=s
$$

代码中要明确：

- 状态是离散编号还是连续向量；
- 是否需要归一化；
- 是否需要堆叠历史帧；
- 是否包含速度、位置、地图、目标点等信息；
- 是否满足近似马尔可夫性。

表格型算法需要离散状态：

$$
Q \in \mathbb{R}^{|\mathcal{S}|\times|\mathcal{A}|}
$$

深度强化学习可以使用连续状态：

$$
Q_\theta(s,a),\quad \pi_\theta(a\mid s)
$$

---

### 3.2 动作 Action

动作空间决定算法选择：

| 动作空间 | 适合算法 |
|---|---|
| 离散动作 | MC control, SARSA, Q-learning, DQN, PPO |
| 连续动作 | REINFORCE Gaussian policy, Actor-Critic, PPO, DDPG, TD3, SAC |

离散动作示例：

$$
\mathcal{A}
=
\{
\text{左},
\text{右},
\text{上},
\text{下}
\}
$$

连续动作示例：

$$
a_t=(\text{steering},\text{throttle})
$$

---

### 3.3 奖励 Reward

奖励是所有算法优化的核心。

常见形式：

$$
r_t
=
w_1 r_{\text{task}}
+
w_2 r_{\text{safety}}
+
w_3 r_{\text{comfort}}
+
w_4 r_{\text{rule}}
$$

代码实现时需要考虑：

- 奖励尺度是否过大；
- 是否需要归一化或裁剪；
- 是否有稀疏奖励；
- 是否有奖励漏洞；
- 终止奖励是否合理；
- 惩罚项是否压倒任务奖励。

---

## 4. 终止条件

代码中必须区分：

| 标记 | 含义 | 是否结束 episode | 是否阻断 TD bootstrap |
|---|---|---|---|
| `terminated` | 任务真实终止 | 是 | 是 |
| `truncated` | 时间上限截断 | 是 | 通常否 |
| `done` | 训练循环结束条件 | 是 | 不一定 |

推荐写法：

```python
done = terminated or truncated
bootstrap_mask = 0.0 if terminated else 1.0
```

TD 目标应写成：

$$
y_t
=
r_t+\gamma(1-\mathrm{terminated}_t)V(s_{t+1})
$$

而不是简单使用：

$$
y_t
=
r_t+\gamma(1-done_t)V(s_{t+1})
$$

这在 Gymnasium 环境中尤其重要。

## 5. MC：蒙特卡洛方法

### 5.1 算法目标

MC 方法通过完整 episode 的实际回报估计价值。

回报为：

$$
G_t
=
R_{t+1}
+
\gamma R_{t+2}
+
\gamma^2R_{t+3}
+
\cdots
$$

状态价值更新：

$$
V(S_t)
\leftarrow
V(S_t)
+
\alpha
\left[
G_t-V(S_t)
\right]
$$

动作价值更新：

$$
Q(S_t,A_t)
\leftarrow
Q(S_t,A_t)
+
\alpha
\left[
G_t-Q(S_t,A_t)
\right]
$$

### 5.2 代码实现要点

MC 必须等 episode 结束后才能更新。

需要存储整条轨迹：

```python
trajectory = [
    (state_0, action_0, reward_1),
    (state_1, action_1, reward_2),
    ...
]
```

从后往前计算回报：

```python
G = 0
for t in reversed(range(len(trajectory))):
    G = reward[t] + gamma * G
```

### 5.3 动作选择

控制任务中通常使用 epsilon-greedy：

$$
A_t
=
\begin{cases}
\text{随机动作}, & \epsilon \\
\arg\max_a Q(S_t,a), & 1-\epsilon
\end{cases}
$$

### 5.4 需要注意

- 只能在 episode 结束后更新；
- 方差较大；
- 适合 episodic 任务；
- first-visit MC 和 every-visit MC 要区分；
- 需要避免回报列表与状态动作列表错位。

---

## 6. TD：时序差分方法

### 6.1 算法目标

TD 方法用一步 bootstrap 更新价值，不必等待 episode 结束。

TD 目标：

$$
y_t
=
R_{t+1}
+
\gamma V(S_{t+1})
$$

TD 误差：

$$
\delta_t
=
R_{t+1}
+
\gamma V(S_{t+1})
-
V(S_t)
$$

更新：

$$
V(S_t)
\leftarrow
V(S_t)
+
\alpha\delta_t
$$

### 6.2 代码实现要点

每一步交互后立即更新：

```python
td_target = reward + gamma * bootstrap_mask * V[next_state]
td_error = td_target - V[state]
V[state] += alpha * td_error
```

### 6.3 需要注意

- TD 是预测方法，不直接解决动作选择；
- 如果要控制，需要扩展到 SARSA 或 Q-learning；
- 终止状态不能 bootstrap；
- TD 偏差较 MC 大，但方差较小。

---

## 7. Q-learning

### 7.1 算法目标

Q-learning 学习最优动作价值函数：

$$
Q^*(s,a)
$$

目标策略为贪心策略：

$$
\pi^*(s)
=
\arg\max_a Q^*(s,a)
$$

### 7.2 更新公式

TD 目标：

$$
y_t
=
R_{t+1}
+
\gamma
\max_{a'}Q(S_{t+1},a')
$$

TD 误差：

$$
\delta_t
=
y_t-Q(S_t,A_t)
$$

更新：

$$
Q(S_t,A_t)
\leftarrow
Q(S_t,A_t)
+
\alpha
\left[
R_{t+1}
+
\gamma
\max_{a'}Q(S_{t+1},a')
-
Q(S_t,A_t)
\right]
$$

### 7.3 动作选择

行为策略通常为 epsilon-greedy：

```python
if random.random() < epsilon:
    action = env.action_space.sample()
else:
    action = np.argmax(Q[state])
```

### 7.4 代码实现要点

```python
current_q = Q[state, action]

if terminated:
    td_target = reward
else:
    td_target = reward + gamma * np.max(Q[next_state])

td_error = td_target - current_q
Q[state, action] += alpha * td_error
```

### 7.5 需要注意

- Q-learning 是 off-policy；
- 行为策略可以探索，目标策略是贪心；
- max 操作可能导致过估计；
- 表格型 Q-learning 要求状态动作离散；
- 连续状态需要离散化或 DQN。

---

## 8. SARSA

### 8.1 算法目标

SARSA 学习当前行为策略的动作价值函数。

它的名字来自：

$$
(S_t,A_t,R_{t+1},S_{t+1},A_{t+1})
$$

### 8.2 更新公式

TD 目标：

$$
y_t
=
R_{t+1}
+
\gamma Q(S_{t+1},A_{t+1})
$$

更新：

$$
Q(S_t,A_t)
\leftarrow
Q(S_t,A_t)
+
\alpha
\left[
R_{t+1}
+
\gamma Q(S_{t+1},A_{t+1})
-
Q(S_t,A_t)
\right]
$$

### 8.3 动作选择

SARSA 需要先在下一状态按当前行为策略选择动作：

```python
next_action = select_action(next_state, epsilon)
```

然后用：

```python
Q[next_state, next_action]
```

构造目标。

### 8.4 与 Q-learning 的代码区别

Q-learning：

```python
target = reward + gamma * np.max(Q[next_state])
```

SARSA：

```python
next_action = select_action(next_state, epsilon)
target = reward + gamma * Q[next_state, next_action]
```

### 8.5 需要注意

- SARSA 是 on-policy；
- 它学习的是包含探索行为的策略；
- 在有风险区域的任务中通常更保守；
- 更新时必须正确保存 next_action。

---

## 9. REINFORCE

### 9.1 算法目标

REINFORCE 直接优化策略：

$$
\pi_\theta(a\mid s)
$$

目标是最大化：

$$
J(\theta)
=
\mathbb{E}_{\tau\sim\pi_\theta}
\left[
G_0
\right]
$$

策略梯度估计为：

$$
\nabla_\theta J(\theta)
\approx
\sum_t
G_t
\nabla_\theta
\log
\pi_\theta(A_t\mid S_t)
$$

### 9.2 策略损失

由于深度学习框架默认最小化损失，使用：

$$
L_{\text{policy}}
=
-\sum_t
G_t
\log
\pi_\theta(A_t\mid S_t)
$$

### 9.3 代码实现要点

需要存储：

```python
log_probs = []
rewards = []
```

采样动作：

```python
dist = Categorical(probs)
action = dist.sample()
log_prob = dist.log_prob(action)
```

episode 结束后计算回报：

```python
G = 0
returns = []
for reward in reversed(rewards):
    G = reward + gamma * G
    returns.insert(0, G)
```

计算损失：

```python
loss = -sum(log_prob * G for log_prob, G in zip(log_probs, returns))
```

### 9.4 需要注意

- 必须等待 episode 结束；
- 方差很大；
- 训练时应采样动作，不应直接 argmax；
- 可以标准化 returns；
- baseline 可降低方差；
- 连续动作需要使用 Normal 分布并计算 log_prob。

## 10. Actor-Critic

### 10.1 算法目标

Actor-Critic 同时学习：

- Actor：策略 $\pi_\theta(a\mid s)$；
- Critic：价值函数 $V_\phi(s)$。

优势估计可用 TD 误差：

$$
\delta_t
=
R_{t+1}
+
\gamma V_\phi(S_{t+1})
-
V_\phi(S_t)
$$

Actor 更新：

$$
L_{\text{actor}}
=
-\operatorname{stopgrad}(\delta_t)
\log\pi_\theta(A_t\mid S_t)
$$

Critic 更新：

$$
L_{\text{critic}}
=
\frac{1}{2}
\left[
R_{t+1}
+
\gamma V_\phi(S_{t+1})
-
V_\phi(S_t)
\right]^2
$$

### 10.2 代码实现要点

```python
log_prob, value = actor_critic(state)
next_value = actor_critic(next_state).value

td_target = reward + gamma * bootstrap_mask * next_value
advantage = td_target - value

actor_loss = -(advantage.detach() * log_prob)
critic_loss = 0.5 * advantage.pow(2)
loss = actor_loss + value_coef * critic_loss
```

### 10.3 需要注意

- Actor 损失中 advantage 要 detach；
- Critic 目标通常要 no_grad；
- 可以加入 entropy bonus；
- Actor 与 Critic 可以共享网络，也可以分离；
- value loss 和 policy loss 的尺度要平衡；
- terminated 与 truncated 要正确处理。

---

## 11. PPO

### 11.1 算法目标

PPO 在 Actor-Critic 基础上限制策略更新幅度。

新旧策略概率比：

$$
r_t(\theta)
=
\frac{
\pi_\theta(A_t\mid S_t)
}{
\pi_{\theta_{\text{old}}}(A_t\mid S_t)
}
$$

裁剪目标：

$$
L^{\mathrm{CLIP}}(\theta)
=
\mathbb{E}_t
\left[
\min
\left(
r_t(\theta)\hat{A}_t,
\operatorname{clip}
(r_t(\theta),1-\epsilon,1+\epsilon)\hat{A}_t
\right)
\right]
$$

代码中最小化：

$$
L_{\text{policy}}
=
-
L^{\mathrm{CLIP}}(\theta)
$$

### 11.2 PPO 需要存储的数据

PPO rollout buffer 至少需要：

```python
states
actions
rewards
terminated
truncated
old_log_probs
values
```

如果使用 GAE，还需要：

```python
next_values
episode_ended_mask
```

### 11.3 GAE 优势估计

TD 误差：

$$
\delta_t
=
R_{t+1}
+
\gamma(1-d_t)V(S_{t+1})
-
V(S_t)
$$

GAE：

$$
\hat{A}_t
=
\sum_{l=0}^{\infty}
(\gamma\lambda)^l
\delta_{t+l}
$$

价值目标：

$$
\hat{R}_t
=
\hat{A}_t+V(S_t)
$$

### 11.4 代码实现要点

```python
ratio = torch.exp(new_log_prob - old_log_prob)

surr1 = ratio * advantage
surr2 = torch.clamp(ratio, 1 - clip_eps, 1 + clip_eps) * advantage

policy_loss = -torch.min(surr1, surr2).mean()
value_loss = 0.5 * (return_target - value).pow(2).mean()
entropy_loss = entropy.mean()

loss = policy_loss + value_coef * value_loss - entropy_coef * entropy_loss
```

### 11.5 需要注意

- old_log_prob 必须在采样时保存；
- 一个 rollout batch 内旧策略应固定；
- 优势要标准化；
- 同一批数据不能训练太多轮；
- 应监控 approx_kl 和 clip_fraction；
- GAE 不能跨 episode reset；
- value clipping 可选；
- 连续动作要正确计算联合 log_prob。

## 12. 各算法实现对比表

| 算法 | 学习目标 | 是否等 episode 结束 | 动作选择 | 更新对象 | 是否 bootstrap | on/off-policy |
|---|---|---|---|---|---|---|
| MC | $V$ 或 $Q$ | 是 | $\epsilon$-greedy | $V/Q$ | 否 | 可 on/off |
| TD(0) | $V$ | 否 | 无控制或固定策略 | $V$ | 是 | on-policy prediction |
| Q-learning | $Q^*$ | 否 | $\epsilon$-greedy | $Q$ | 是 | off-policy |
| SARSA | $Q^\pi$ | 否 | $\epsilon$-greedy | $Q$ | 是 | on-policy |
| REINFORCE | $\pi_\theta$ | 是 | 策略采样 | policy | 否 | on-policy |
| Actor-Critic | $\pi_\theta,V_\phi$ | 否 | 策略采样 | policy + value | 是 | on-policy |
| PPO | clipped policy | rollout 后更新 | 策略采样 | policy + value | 是 | on-policy |

## 13. 代码实现总检查清单

### 13.1 算法目标

实现前必须确认：

- 是预测问题还是控制问题；
- 是学习 $V(s)$、$Q(s,a)$，还是 $\pi(a\mid s)$；
- 是 on-policy 还是 off-policy；
- 动作是离散还是连续；
- 是否需要神经网络。

### 13.2 终止条件

需要明确：

```python
done = terminated or truncated
bootstrap_mask = 0.0 if terminated else 1.0
```

### 13.3 动作选择

价值类算法：

```python
epsilon_greedy(Q[state])
```

策略梯度类算法：

```python
action ~ pi_theta(. | state)
log_prob = log pi_theta(action | state)
```

评估时通常使用：

```python
argmax Q[state]
```

或：

```python
mean action / deterministic action
```

### 13.4 价值更新

价值类算法要明确 TD target：

- MC：$G_t$；
- TD：$r+\gamma V(s')$；
- Q-learning：$r+\gamma\max_{a'}Q(s',a')$；
- SARSA：$r+\gamma Q(s',a')$；
- Actor-Critic：$r+\gamma V(s')$；
- PPO：GAE + return target。

### 13.5 策略更新

策略梯度类需要：

- 保存 log_prob；
- 保存 reward；
- 计算 return 或 advantage；
- 用负号构造 loss；
- advantage 要 detach；
- 可加入 entropy bonus。

### 13.6 价值评估

训练中应记录：

- episode return；
- episode length；
- success rate；
- collision / failure rate；
- value loss；
- policy loss；
- entropy；
- epsilon；
- approx KL；
- clip fraction。

### 13.7 数值稳定

需要考虑：

- reward clipping；
- return normalization；
- advantage normalization；
- gradient clipping；
- target network；
- learning rate schedule；
- seed 固定；
- NaN 检查；
- device 转换；
- dtype 统一。

### 13.8 模型保存与评估

必须做到：

- 先保存模型，再绘图；
- 保存 config；
- 保存训练日志；
- 训练策略和测试策略分开；
- 测试时关闭探索；
- 支持加载 checkpoint；
- 支持多 seed 实验。

---

## 14. 最简总结

从 MC 到 PPO，代码实现需要围绕五个问题设计：

$$
\boxed{
\text{学什么？怎么采样？何时结束？用什么目标更新？如何评估？}
}
$$

具体对应：

1. 学什么：$V$、$Q$、$\pi$、$V+\pi$；
2. 怎么采样：$\epsilon$-greedy 或策略分布采样；
3. 何时结束：terminated / truncated / max steps；
4. 用什么目标更新：return、TD target、advantage、clipped objective；
5. 如何评估：return、success rate、loss、entropy、KL、clip fraction。

最终可以记住：

$$
\text{MC 用完整回报，TD 用一步预测，Q-learning 用最大 Q，SARSA 用实际下一动作，REINFORCE 用回报修正策略，Actor-Critic 用 Critic 降方差，PPO 用裁剪限制策略更新幅度。}
$$
