# 无人驾驶强化学习决策规划算法与数据集综述

## 1. 决策与规划的区别

无人驾驶中的强化学习主要用于两个层级：

| 层级 | 主要问题 | 输出 |
|---|---|---|
| 智能决策 | 当前场景下应该采取什么驾驶行为 | 保持车道、换道、让行、超车、停车等 |
| 运动规划 | 自车未来几秒应该如何运动 | 轨迹点、速度曲线、转向/油门/刹车 |

决策层可写为：

$$
s \rightarrow a_{\text{behavior}}
$$

规划层可写为：

$$
s \rightarrow \tau = \{(x_t,y_t,v_t)\}_{t=1}^{T}
$$

强化学习通常把问题建模为 MDP：

$$
\mathcal{M}=(\mathcal{S},\mathcal{A},P,R,\gamma)
$$

目标是最大化累计折扣回报：

$$
J(\pi)=
\mathbb{E}_{\pi}
\left[
\sum_{t=0}^{T}\gamma^t r_t
\right]
$$

---

## 2. 强化学习在智能决策中的应用

智能决策关注“做什么行为”，典型任务包括：

- 跟车；
- 换道；
- 超车；
- 匝道汇入；
- 路口让行；
- 无保护左转；
- 环岛通行；
- 多车交互博弈。

行为动作通常是离散的：

$$
\mathcal{A}
=
\{
\text{保持车道},
\text{左换道},
\text{右换道},
\text{加速},
\text{减速},
\text{停车等待}
\}
$$

### 主流决策算法

| 类别 | 代表算法 | 适用场景 |
|---|---|---|
| 表格型价值学习 | Q-learning, SARSA | 小规模离散状态动作 |
| 深度价值学习 | DQN, Double DQN, Dueling DQN, Rainbow | 离散驾驶行为决策 |
| 策略梯度 | REINFORCE, PPO, TRPO | 离散或连续决策 |
| Actor-Critic | A2C, A3C, PPO, SAC | 交互复杂、状态连续 |
| 多智能体 RL | MADDPG, MAPPO, QMIX | 多车交互、协同/博弈 |
| 离线 RL | CQL, IQL, BCQ, TD3+BC | 基于真实轨迹数据训练 |

## 3. 强化学习在规划中的应用

规划层关注“未来怎么走”。输出可能是轨迹：

$$
\tau
=
\{(x_1,y_1,v_1),\ldots,(x_T,y_T,v_T)\}
$$

也可能是低层控制：

$$
a_t=(\text{steering},\text{throttle},\text{brake})
$$

规划奖励通常包含：

$$
r_t
=
w_1 r_{\text{safety}}
+
w_2 r_{\text{progress}}
+
w_3 r_{\text{comfort}}
+
w_4 r_{\text{rule}}
+
w_5 r_{\text{route}}
$$

其中：

- $r_{\text{safety}}$：碰撞、TTC、最小距离；
- $r_{\text{progress}}$：路线前进；
- $r_{\text{comfort}}$：加速度、jerk、横向加速度；
- $r_{\text{rule}}$：红灯、限速、车道线；
- $r_{\text{route}}$：是否沿导航路线行驶。

### 主流规划算法

| 类别 | 代表算法 |
|---|---|
| 传统搜索规划 | A*, Hybrid A*, lattice planner |
| 采样规划 | RRT, RRT*, PRM |
| 优化规划 | MPC, iLQR, SQP, trajectory optimization |
| 模仿学习规划 | Behavior Cloning, ChauffeurNet 类方法 |
| 强化学习规划 | PPO, SAC, TD3, DDPG |
| 离线强化学习规划 | CQL, IQL, TD3+BC |
| 多智能体规划 | MAPPO, MADDPG, QMIX |
| 学习 + 优化混合 | RL + MPC, RL + rule-based planner |

## 4. 决策方向主流数据集

严格来说，强化学习需要交互环境；真实世界数据集更多用于行为建模、模仿学习、离线强化学习和策略评估。

| 数据集 | 场景 | 适合任务 |
|---|---|---|
| INTERACTION | 路口、环岛、汇入、交互场景 | 交互决策、让行、博弈、多车行为 |
| highD | 德国高速公路 | 跟车、换道、超车、风险评估 |
| inD | 城市路口 | 路口通行、行人车辆交互 |
| rounD | 环岛 | 环岛汇入、让行、交互行为 |
| exiD | 高速出入口 | 匝道汇入、驶出、合流 |
| NGSIM | 高速车流 | 跟车、换道、离线 RL |
| Waymo Open Motion Dataset | 城市多智能体轨迹 | 交互预测、行为建模、sim agents |
| Argoverse 2 Motion Forecasting | 城市交互轨迹 | 轨迹预测、意图识别、交互建模 |
| nuScenes Prediction | 城市场景 | 轨迹预测、感知-预测-决策研究 |

## 5. 规划方向主流数据集与平台

| 数据集 / 平台 | 类型 | 适合任务 |
|---|---|---|
| nuPlan | 真实数据 + 闭环规划基准 | 学习型规划、闭环规划评估、模仿学习、离线 RL |
| CARLA / CARLA Leaderboard | 仿真平台 + 闭环基准 | 在线 RL、端到端驾驶、闭环控制、复杂场景测试 |
| Waymo Open Motion Dataset | 真实多智能体轨迹 | 预测-规划联合、交互式规划、sim agents |
| nuScenes | 多模态真实驾驶数据 | 开环规划、端到端规划、预测-规划联合 |
| Argoverse 2 | 轨迹预测与地图数据 | 预测模块、交互建模、规划前置任务 |
| INTERACTION | 强交互轨迹数据 | 多车交互规划、让行、汇入、路口决策 |

## 6. 决策数据集和规划数据集的区别

| 维度 | 决策数据集 | 规划数据集 |
|---|---|---|
| 关注重点 | 行为选择 | 自车未来轨迹 |
| 输出形式 | 换道、让行、跟车、超车 | 轨迹点或控制序列 |
| 是否强调闭环 | 不一定 | 强调闭环更重要 |
| 常用指标 | 成功率、碰撞率、行为准确率 | 碰撞率、路线进度、舒适性、交通规则 |
| 典型数据集 | INTERACTION, highD, inD, NGSIM | nuPlan, CARLA, Waymo Motion, nuScenes |

## 7. 研究选型建议

### 智能决策方向

如果研究“强化学习智能决策”，建议：

1. 换道/跟车：highD、NGSIM；
2. 匝道汇入：exiD、INTERACTION；
3. 路口/环岛交互：INTERACTION、inD、rounD；
4. 多车交互：Waymo Motion、INTERACTION；
5. 算法起点：DQN、Double DQN、Dueling DQN；
6. 连续动作：PPO、SAC、TD3；
7. 多车交互：MAPPO、MADDPG。

### 规划方向

如果研究“强化学习规划”，建议：

1. 在线强化学习：CARLA；
2. 闭环规划评估：nuPlan；
3. 离线规划学习：nuPlan、Waymo Motion、nuScenes；
4. 算法起点：PPO、SAC、TD3；
5. 工程混合：RL + MPC、RL + rule-based planner；
6. 若强调安全性：加入碰撞惩罚、TTC、CBF 或规则约束。

---

## 8. 总结

无人驾驶中，强化学习主要用于：

$$
\text{决策层：状态} \rightarrow \text{驾驶行为}
$$

以及：

$$
\text{规划层：状态} \rightarrow \text{未来轨迹或控制}
$$

主流算法包括：

- 离散决策：Q-learning、DQN、Double DQN、Dueling DQN、Rainbow；
- 连续规划：DDPG、TD3、SAC、PPO、TRPO；
- 多车交互：MADDPG、MAPPO、QMIX；
- 离线学习：CQL、IQL、BCQ、TD3+BC；
- 混合规划：RL + MPC、RL + 规则规划器。

主流数据集可以概括为：

- 决策：INTERACTION、highD、inD、rounD、exiD、NGSIM、Waymo Motion、Argoverse 2；
- 规划：nuPlan、CARLA、Waymo Motion、nuScenes、Argoverse 2；
- 闭环规划首选：nuPlan 和 CARLA；
- 交互决策首选：INTERACTION、highD 系列和 Waymo Motion。
